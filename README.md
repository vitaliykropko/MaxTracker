# MaxTracker

Расширение Chrome для работы с обращениями в MAX. В карточке сообщения видны исполнитель и состояние, а в боковой панели доступна личная статистика. Исключения настраиваются в меню чата «Инфо» → «Ещё» → «Исключить чат».

## Установка и обновление

Скачайте `MaxTracker-Colleague-*.zip` из [последнего релиза](https://github.com/vitaliykropko/MaxTracker/releases/latest) и распакуйте его. В архиве лежат готовая папка `extension` и инструкция `УСТАНОВКА.txt` для первой установки и обновления. Для скачивания нужен доступ к приватному репозиторию.

## Сборка

Понадобится Node.js 22 или новее. Результат сборки находится в `extension`.

```sh
npm ci
npm run build
npm test
```

Для браузерных тестов дополнительно установите зависимости из `requirements.txt` и Chromium для Playwright, затем запустите `npm run test:e2e`. Тесты поднимают собственный хаб и используют тестовые чаты.
